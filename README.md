# BenDk97 Neo Geo ports: bug tracker

Bug reports and feature requests for my Neo Geo ports (Snow Bros, Shadow of the Beast, Knights of the Round, Cosmo Gang the Video, OutRun, Sword of Sodan).

Downloads: https://bendk97.itch.io

Suivi des bugs de mes portages Neo Geo. Utilise le bouton **New issue** et remplis le formulaire (jeu, version, plateforme, comment reproduire). Une vidéo ou une capture aide beaucoup.

Unofficial fan projects, not affiliated with the original rights holders. No game data is hosted here: do not upload ROMs or copyrighted files in issues.
Projets de fan non officiels. N'envoie jamais de ROM ni de fichiers protégés dans les tickets.
