# BenDk97 Neo Geo ports: bug tracker

Bug reports and feature requests for my Neo Geo ports: Snow Bros, Shadow of the Beast, Knights of the Round, Cosmo Gang the Video, OutRun, Sword of Sodan and R-Type.

Downloads: https://bendk97.itch.io

## How to report a bug

Click **New issue** and fill in the form: game, version, platform, and how to reproduce it. A video or a screenshot helps a lot.

## Please note

These are unofficial fan projects, not affiliated with the original rights holders. No game data is hosted here: do not upload ROMs or other copyrighted files in issues.
